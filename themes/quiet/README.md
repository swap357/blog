# Quiet

A small Hugo theme with native fonts, warm neutrals, and no JavaScript.
Tested with Hugo **0.166.0**, standard edition.

Templates live in `layouts/`; the stylesheet is `assets/css/main.css`.
Hugo minifies and fingerprints CSS. The home feed contains complete articles.
Navigation expects Writing, About, and Projects pages.

See the [site README](../../README.md) for development, writing, and deployment,
and [checks](../../tests/README.md) for validation.
